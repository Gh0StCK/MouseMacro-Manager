MouseMacro Manager — WebView2 / AutoHotkey v2
Сборка: 22.11.2026 — HTML UI без браузерных команд + расширенные горячие клавиши
==============================================

ЗАПУСК
1. Распаковать архив в НОВУЮ папку.
2. Для сохранения своих макросов скопировать в неё MouseMacro.ini и,
   если есть, папку MouseMacro_Images из прежней версии.
3. Запустить «Start_MouseMacro.ahk» с установленным AutoHotkey v2 (64-bit).
4. При первом запуске разрешить скачивание WebViewToo с GitHub:
   загрузчик получает фиксированный исходный архив и извлекает библиотеку.
   Он не запускает сторонних установщиков. В дальнейшем интернет не нужен.
   WebView2 Runtime должен присутствовать в Windows.

ВАЖНО: Не запускать старую и новую версии одновременно — горячие клавиши
конфликтуют. Старую копию INI сохранить до первого теста.

НОВОЕ: ГОРЯЧИЕ КЛАВИШИ И КНОПКИ МЫШИ
• В окне «Новая запись» или «Сменить клавишу» нажмите нужную клавишу
  либо XButton1 / XButton2 (боковые кнопки мыши) или среднюю кнопку.
  Также поддерживаются комбинации с Ctrl/Alt/Shift, F1–F24, NumPad,
  навигационные, некоторые мультимедийные и знаковые клавиши.
• Никакие кнопки в HTML сами по себе не запускают макрос — только
  добавляют шаг или настраивают действие. Горячая клавиша запускает весь макрос.
• При активном окне MouseMacro боковые кнопки мыши больше не выполняют
  браузерные «Назад»/«Вперёд», если не назначены макросу.
• Назначенная глобальная горячая клавиша перехватывается в других программах.
  Например, XButton1, назначенная макросу, перестанет быть «Назад» в браузере,
  пока работает MouseMacro. Одиночные буквы тоже забирают обычный ввод —
  выбирайте их осознанно. Для специальных кнопок мыши 6+ может понадобиться
  настройка драйвера мыши, чтобы они выдавали обычные клавиши.
• Зарезервированы: Win-сочетания, F9, Ctrl+Alt+R, Ctrl+Alt+Esc,
  Alt+F4, Alt+Tab, Ctrl+Shift+Esc, Ctrl+D и Ctrl+Z (редактор),
  одиночные клавиши управления Esc/Tab/Enter/Backspace/Delete/Space и др.,
  а также голые LButton/RButton/колесо для защиты обычной работы мыши.

HTML-ОКНО
• WebView2 используется только как оболочка для локального HTML/CSS/JS.
  Отключены браузерные клавиатурные команды, масштабирование, меню контекста,
  инструменты разработчика, навигация на другие адреса и переходы
  «Назад»/«Вперёд» боковыми кнопками мыши.
• Текстовые поля и необходимый обмен командами с AHK сохранены.

ОСНОВНЫЕ ВОЗМОЖНОСТИ
• Запись левых, правых и средних кликов, прокрутки WheelUp/WheelDown,
  координат и пауз. Горячие клавиши для разных макросов.
• Воспроизведение с повторами; F9 — экстренная остановка.
• Изменение одного шага (кнопка мыши / колесо, X, Y, задержка).
• Двойной щелчок по шагу — только изменение его паузы.
• Массовая смена пауз по Ctrl/Shift-выделению и удаление нескольких шагов.
• Дублирование выбранных шагов (кнопка или Ctrl+D). Копии вставляются
  подряд сразу после последнего выбранного шага.
• Отмена до 10 последних изменений шагов (кнопка или Ctrl+Z).
  История хранится только в памяти, сбрасывается после перезапуска.
  Удаление целого макроса и изменение горячих клавиш в неё не входят.
• Ожидание появления изображения и проверка его наличия без клика.
  Функция «Клик по изображению» УДАЛЕНА — старые шаги этого типа не
  стираются из INI, но макрос с ними не запускается, пока их не удалить.
• Изменения записываются в MouseMacro.ini; предыдущий файл копируется
  в MouseMacro.ini.bak при успешной попытке сохранения.

ЧТО ИСПРАВЛЕНО В ЭТОЙ СБОРКЕ
• Отказ от редакторской операции при ошибке записи INI: исходные шаги
  остаются без изменений в памяти; не появляется ложное «сохранено».
• Аналогичный откат при неуспехе переименования, удаления/копирования
  макроса, смены клавиши или изменения повторов через WebView2.
• Отображение списков: меньше лишних перерисовок, лучше сохранение фокуса.
• Пустое поле числовой настройки изображения не принимается за 0.
• Формирование JSON корректно экранирует управляющие символы.
• Добавлены дублирование и ограниченная история отмены изменений шагов.

НЕ ПОДДЕРЖИВАЕТСЯ
• Запись текста с клавиатуры, перетаскивание зажатой мышью,
  горизонтальная прокрутка, точные дельты высокоточного колеса.
• Копирование выделенных шагов между разными макросами пока не добавлено.

ПРОВЕРКА
• JavaScript — синтаксис проходит node --check.
• HTML — 11 автоматических сценариев прошли в Chromium/Playwright.
• Исходник AHK — статическая проверка структуры и наличия обработчиков.
• Архив — тест целостности ZIP.
• НЕТ запуска AutoHotkey/WebView2 в настоящей Windows в среде сборки.
  Реальное воспроизведение/захват мыши, сочетания клавиш и WebView2 bridge
  необходимо проверить самостоятельно до использования в важных задачах.

Для первого теста запиши безопасный макрос из двух кликов на пустом окне,
проверь воспроизведение и F9, потом прокрутку, дублирование, Ctrl+Z и
повторное открытие приложения с сохранённым INI.
