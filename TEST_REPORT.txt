MouseMacro Manager — протокол проверки 22.11.2026
===================================================
Окружение: Chromium (headless, Playwright), Node.js, Python, Linux.

ПРОЙДЕНО — HTML/JavaScript:
 1. Множественное выделение Ctrl/Shift и якорь диапазона
 2. Команда дублирования и Ctrl+D
 3. Команда отмены и Ctrl+Z
 4. Двойной щелчок открывает редактор паузы, Enter применяет
 5. Массовая пауза: пустое поле отклоняется, Enter применяет значение
 6. Редактор прокрутки: X, Y и пауза передаются корректно
 7. Пустое числовое поле ожидания изображения отклоняется
 8. Состояния «Записать / Сохранить / Отмена» переключаются
 9. Список макросов не пересоздаётся при каждом обновлении статуса
10. Интерфейс без горизонтального выхода за экран на ширинах 850–1300px
11. Необработанных исключений JavaScript нет

ПРОЙДЕНО — статические проверки:
 - Синтаксис JS через node --check
 - Баланс скобок AHK (лексический статический тест)
 - Наличие обработчиков HTML ↔ AHK, парсера INI, обработчиков колеса и F9
 - Фиксированная ревизия библиотеки WebViewToo в запускном файле

НЕ ПРОВЕРЕНО:
 - Выполнение AHK v2 в Windows (интерпретатор недоступен на Linux)
 - Нативный WebView2 bridge, захват мыши, восстановление курсора и F9
 - Фактическая запись/загрузка INI в Windows, негативные I/O сценарии
 - DPI 125/150/200% в Windows и многомониторный режим

Поэтому это тестовая сборка, а не подтверждённый бездефектный релиз.

АРХИВ: Все пути/имена файлов содержат только ASCII. Файл запуска Start_MouseMacro.ahk.


ДОПОЛНЕНИЕ 22.11.2026: WebView2 UI-only + горячие клавиши
---------------------------------------------------------
• Проверен HTML/JS: синтаксис в Node.js, сценарии в Chromium через Playwright.
• Пройдены 21 проверки: назначение F13, Ctrl+Shift+F6, XButton1,
  Ctrl+XButton2; отклонение F9, Win, Ctrl+Alt+R/Delete, Alt+F4,
  Ctrl+Z; NumPad, физическая кириллическая раскладка (KeyA), знаковые
  клавиши (sc00C); закрытие модального окна и отсутствие JS-ошибок.
• Защита браузерной навигации: отрабатывается на уровнях HTML,
  WebView2 Settings, NavigationStarting и AHK XButton/WM_APPCOMMAND.
• Код AHK прочитан и сравнен с предыдущей сборкой; движок воспроизведения,
  формат INI и запись шагов не изменены.
• Работа WebView2, Windows mouse hooks и назначенных клавиш в реальной
  Windows-среде не проверена: тест на ПК пользователя обязателен.
